# CHAOS website

Static site: `index.html` plus the `img/` folder. No build step.

## Put it online with GitHub Pages
1. Create a GitHub account and click New repository. Name it `chaos` (public).
2. Click "uploading an existing file", drag in everything from this folder (index.html, img, .nojekyll), then Commit.
3. Open Settings > Pages. Under Source choose "Deploy from a branch", branch `main`, folder `/ (root)`, then Save.
4. After a minute your site is at https://YOUR-USERNAME.github.io/chaos/

## Use your own domain
Settings > Pages > Custom domain, enter your domain, then add the DNS records GitHub shows at your domain registrar.

## Before a real launch
Prices and products in index.html are samples. The signup form and social links are placeholders. There is no real checkout yet.
